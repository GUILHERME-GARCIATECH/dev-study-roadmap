# Tipos em JavaScripts
> O JavaScript é uma linguagem dinamicamente tipada que possui 8 tipos de dados, divididos em duas categorias: Primitivos e Objetos (Não Primitivos). O tipo de uma variável é definido automaticamente pelo valor atribuído a ela

## Tipos primitivos (7 tipos)
> São os dados mais simples e imutáveis, que armazenam um único valor na memória:

 - String: Representa textos e caracteres (ex: "Olá, Mundo!")
 - Number: Representa todos os números, sejam inteiros ou com casas decimais (ex: 42, 3.14).
 - Boolean: Valores lógicos de verdadeiro ou falso.
 - Undefined: O valor de uma variável declarada, mas que ainda não recebeu nenhum valor atribuído.
 - Null: Representa a ausência intencional de qualquer valor
 - BigInt: Usado para representar números inteiros extremamente grandes, que ultrapassam o limite seguro do tipo Number.
 - Symbol: Cria um identificador único e exclusivo que não pode ser alterado.

 ## Tipos não primitivos (1 tipo)
 > São estruturas de dados mais complexas que servem como coleções ou representações mais elaboradas, sendo armazenadas por referência.

 - Object: O tipo base de todas as estruturas complexas do JavaScript. São Coleções de propriedades e dados associados a chaves (ex: { nome: "Ana", idade: 25 }).
    - Array: Listas ordenadas de valores acessadas por índices numéricos (ex: [10, 20, 30]).
    - Function: Blocos de código reutilizáveis que podem ser chamados e executados.
    - Outros: Inclui estruturas como Date (datas) e RegExp (expressões regulares).
